## 2. 필수 품질 검수 시나리오 (Critical Test Cases 10종)

### TC-01: ODsay 환승 횟수 4개 핵심 사례 검증 (P0)
- **사례 A (지하철 직통: 당산 ➔ 합정)**: 탑승 1구간 ➔ 기대값: `totalTransfers = 0`
- **사례 B (버스 2회 승차)**: 버스 2구간 ➔ 기대값: `totalTransfers = 1`
- **사례 C (지하철 호선 환승: 2호선 ➔ 3호선)**: 지하철 2구간 ➔ 기대값: `totalTransfers = 1`
- **사례 D (혼합: 버스 ➔ 지하철 ➔ 버스)**: 탑승 3구간 ➔ 기대값: `totalTransfers = 2`
*검증 기준: `subPath`의 대중교통 탑승 구간 카운트 공식(`Math.max(0, transitLegCount - 1)`) 검증.*

### TC-02: 주변 역·정류장 중복 제거 및 하버사인 직선거리 검증 (P0)
1. 동일한 정류장 명칭(예: "강남역")을 가진 상행/하행 정류장이 각각의 고유 `stationID`로 분리되어 목록에 모두 유지되는지 검증.
2. ARS-ID가 없는 복수의 지하철역(출구/호선 구분)이 하나로 합쳐지지 않고 모두 유지되는지 검증.
3. 기준 좌표와 시설 좌표 간의 직선거리(m)가 하버사인 공식으로 정확히 계산되는지 검증.

### TC-03: 저장 경로 라이프사이클 및 앱 재실행 원본 보존 검증 (P0 - 복원)
1. 사용자가 "집 ➔ 회사 (08:30 출발)" 경로를 저장.
2. **앱을 완전히 종료 후 재실행**하여 홈 화면에 해당 카드가 영속적으로 표시되는지 확인.
3. 카드 터치하여 임시 변경 시트에서 출발지를 "카페", 시각을 "09:00"으로 1회 검색 실행.
4. 결과 화면 확인 후 뒤로가기 시, 홈 화면 원본 카드가 출발지 "집", 시각 "08:30"으로 훼손 없이 유지되는지 검증.

### TC-04: 시간 계산, 자정 경과 및 지난 시각 처리 검증 (P0)
1. 현재 시각이 09:00일 때 저장 카드 시간이 08:30인 경우, 자동으로 "내일 08:30"으로 쿼리 파라미터가 생성되는지 검증.
2. 출발 시각 23:40, 소요시간 40분일 때 도착 시각이 `00:20 (익일)`로 정확히 계산되는지 검증.
3. 결과 화면에 단순 가산값 안내 배너가 의무 렌더링되는지 확인.

### TC-05: 도보거리 결측치(`undefined`) 정렬 왜곡 방지 검증 (P1 - 신규)
1. 도보 이동 거리 정보가 없는 경로가 '도보 적은 순' 정렬 시 실제 0m(도보 없음) 경로보다 위에 노출되지 않고 최하위(Infinity)로 정렬되는지 검증.

### TC-06: 백업 병합 시 HOME/WORK 충돌 해결 및 트랜잭션 롤백 검증 (P0 - 신규)
1. 기기에 등록된 [🏠 집] 주소와 가져온 백업 파일의 [🏠 집] 주소가 다를 때 충돌 해결 선택 팝업이 뜨는지 검증.
2. 복원 파일 쓰기 도중 에러가 발생했을 때, Dexie 트랜잭션에 의해 직전 상태(`pre_restore_backup`)로 완벽히 롤백되는지 검증.
3. `recentPlaces`가 백업 파일에서 제외되어 있는지 확인.

### TC-07: 최신 요청 번호(`latestRequestId`) 및 경쟁 상태 방지 (P1 - 신규)
1. 검색 조건을 매우 빠르게 3회 연속 변경 요청.
2. 1번 요청이 네트워크 지연으로 가장 늦게 에러(또는 응답)로 반환되더라도, 3번 성공 화면을 덮어쓰지 않는지 검증.

### TC-08: DB 쓰기 실패 시 에러 명확성 및 성공 오인 방지 (P1 - 복원)
1. 스토리지 오류 시 "저장되었습니다"와 같은 성공 메시지가 절대 뜨지 않고, 실패 토스트가 출력되며 롤백되는지 검증.

### TC-09: Mock 뱃지 및 Stale 캐시 타임스탬프 표시 검증 (P1 - 복원)
1. 개발 환경에서 Mock 어댑터 동작 시 상단에 주황색 **[MOCK 가상 데이터 모드]** 뱃지 노출 확인.
2. API 쿼터 초과 시 반환된 30분 Stale 캐시에 **[오래된 데이터 (오프라인/한도초과)]** 뱃지 및 **조회 시점 타임스탬프** 노출 확인.

### TC-10: Android APK 실기기/에뮬레이터 종합 검증 (P1 - 복원)
1. Android 빌드본에서 Capacitor Geolocation 권한 획득 정상 동작 검증.
2. Cloudflare Worker 프록시를 통한 외부 API 정상 호출 및 **APK 바이너리에 Secret Key 미포함(grep 검증)** 확인.
3. 안드로이드 파일 시스템 내 백업 JSON 파일 내보내기/가져오기 정상 동작 검증.
